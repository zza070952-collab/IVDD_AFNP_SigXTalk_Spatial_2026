# Execution and interpretation boundaries

The wrapper distinguishes a command that ran now, a verified current output reused from an earlier completed stage, an unavailable input and an explicitly failed computation. Reuse is not reported as fresh training. All raw routes retain the frozen K5 and original gene memberships; aliases are identifier mappings only.

A valid current raw-count contract can be reused after recomputing the seeded cell order/groups from actual cell-level tables, verifying public raw-source hashes and checking contract hashes in either the preparer's own receipt or the new formal input provenance. This prevents accidental recompression of a trained gzip input from breaking its byte identity. Partial existing inputs stop for review. They are not overwritten with a new selection.

A completed official formal run requires new real input provenance, the exact configuration hash, pinned source files, completed epochs/seed, the complete prediction hash and R→Python→R completion. A CSV containing scores alone does not establish this closure. Technical demo and formal outputs remain separate. Downstream PRS can resume a completed unchanged HGNN without repeating training; no automatic hyperparameter retry occurs.

The fixed spatial100-UMI analysis is executed once only when no prior draw/output exists. Matching completed metadata, ROI, configuration and protected source hashes allow reuse. Missing/changed/partial completion metadata causes an explicit failure; the dispatcher does not redraw to obtain a desired anatomical contrast. Replotting existing source tables is a separate deterministic operation.

Four main figures present adult cohort coverage, fixed-program expression, new official predictions and mouse anatomical context with depth sensitivity. Figure export does not perform or assert manual visual QA. Raw preparer smoke fixtures, CI and mock protocol tables are never used as research evidence. No wet-laboratory results are generated.

The from-raw entry points and own-code computational chain are supplied. A new clean-machine from-raw run of the assembled workflow has not been validated merely by assembling these components. Actual command/exit/hash receipts and successful measured outputs are needed before strengthening that claim. In particular, an unavailable R environment or unclosed official technical smoke cannot be replaced by historical pathways or positive synthetic outputs.
