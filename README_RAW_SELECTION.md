# Genuine raw-count SigXTalk input preparation

Merge this module's `scripts/`, `resources/metadata/`, `config/` and `tests/` with the human module in the new own-code repository. The executable is `scripts/prepare_sigxtalk_raw.py`; `scripts/support_af_identity.py` contains the study's own fixed AF QC/identity code. Neither file vendors SigXTalk, CellChat, Scanpy, cNMF or UCell source. Dependencies are installed separately using the human module's isolated historical discovery environment. No large files or individual-cell barcode resources are distributed.

```bash
python scripts/prepare_sigxtalk_raw.py --config config/raw_selection.example.json --project-root NEW_ANALYSIS_ROOT --from-raw
python scripts/prepare_sigxtalk_raw.py --config config/private-raw-selection.json --project-root NEW_ANALYSIS_ROOT --from-cached-inputs
```

The raw mode downloads the exact eight disease AF and eight disease NP libraries from official GSE230808 GEO supplementary URLs. It runs the public human module's discovery QC/identity/UCell interface with the frozen K5, without cNMF refitting. It runs the fixed AF pass once: 300–9,000 detected features, mitochondrial percentage at most25%, positive UMI; per-library official Scanpy Scrublet (expected doublet rate0.06, simulation ratio2,30 PCs, seed20261017); normalise10,000/log1p, batch-aware2,000 HVGs, scale cap10,30 PCs,15 neighbours, Leiden resolution0.5/two iterations and the retained marker rules. AF chondrocytic marker support retains AF tissue origin. A Scrublet failure stops the stage rather than accepting a fallback singlet population. Compatible historical packages and successful execution remain necessary; supplying this code does not claim that a clean-machine raw run has already succeeded.

Cached mode requires genuine per-cell discovery metadata, discovery UCell scores and AF QC/identity metadata. It hashes these read-only files, independently recomputes cell selection and resolves the selected samples' real raw GEO matrices. It does not accept a donor-summary table, infer expression from scores, or select cells from a published hardcoded barcode list. A private optional `reference_selected_metadata` path compares a previous selection only after independent sampling; it never drives sampling. Metadata and raw directories may be anywhere readable. Missing raw files are downloaded only within the new analysis root; `--no-download` requires all selected triplets to be present.

The selection is fixed at seed20261017: high-confidence NP cells are separated by each donor's actual GEP2 UCell lower/upper quartiles; both tails need at least20 cells and distinct quartiles. The expected six eligible donor pairs each contribute at most150 cells per NP group and at most150 matched broad-stromal AF cells. Donors, candidate IDs and sampled IDs are sorted in the same declared order before seeded sampling. Actual counts can be below the cap. A changed eligible-donor count stops execution for investigation; the code never adjusts thresholds to recover a desired number.

The output contract is gene×cell `02_sigxtalk_official_new/input/counts.mtx.gz`, one gene per line in `genes.tsv`, and exactly aligned cell rows in `meta.tsv` with `cell_id`, `gsm`, `donor_id`, `tissue`, `bridge_group` and actual QC/score fields. Counts are finite nonnegative integer values read from public 10x files. Only Gene Expression features are included. Submitted duplicate symbols are made unique, without changing or summing expression rows for the official new raw-input universe. Across samples, shared names must also have matching feature IDs. Differing feature universes stop by default; an explicitly enabled common-feature intersection is recorded together with per-cell UMI loss.

Raw metadata-to-barcode matching, UMI agreement, gene alignment, feature-universe and source-file SHA256 audits are newly computed. Original NP QC summed duplicate canonical symbols before counting features, whereas AF used made-unique submitted symbols. The audit therefore reports both true raw positive-row feature counts and the historical-equivalent feature count. This can explain identical UMI totals with a small raw/cached feature-count difference without altering the official new raw expression matrix.

Execution receipts are in `00_audit/RAW_SELECTION_EXECUTION.json` and `00_audit/NEW_RAW_INPUT_FILES.tsv`; detailed barcode/gene audits are in `02_sigxtalk_official_new/`. These runtime products are private analysis outputs, not files to commit wholesale. A failed run preserves PARTIAL_FAILED, logs and available audits. Successful preparation establishes valid model inputs; it is not a SigXTalk execution or a communication/causality result.

Run `python -m unittest discover -s tests -p test_raw_selection.py -v` for tiny structural checks. They validate raw integer preservation, exact metadata ordering, conservative pairing and deterministic selection only, and contain no substitute research observations.
