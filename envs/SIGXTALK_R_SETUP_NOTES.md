# R environment setup and certification

The bootstrap YAML requests a compatible Seurat5.2.1 / SeuratObject5.0.2 pair under R4.4. Do not let an unbounded update replace SeuratObject with5.4: it makes internal calls from Seurat5.2.1 fail on the defunct `slot=` interface. If no R4.4 build of5.0.2 is available, a fresh explicitly verified5.2.0 pair is a documented alternative; do not silently claim the preferred version installed. Save the final actual package/session and conda environment records after solving.

This is a bootstrap list, not a complete final dependency lock. Install remaining packages from their verified official sources into the isolated environment/project library: CellChat v2.1.2 commit a0d3b2d231d46c8787177fffeac908270c253747, presto v1.1.0 commit b5df6ee6097eb62522f2e557aa93ac21bab2d05f, the actual compatible tidyfst/fst and NMF versions, and SigXTalkR pinned commit4d8055c6c9539ff9e6875d0e731d933cb2dd69f9. Consult actual DESCRIPTION imports; do not downgrade a compatible recipes/Matrix library merely because DESCRIPTION lists historical archive Remotes. Use an explicit source install after satisfying dependencies, with no shared-library mutation and no upstream upgrade=always.

When a source upgrade replaces a package already loaded by an installation process, verify it in a fresh R process. For example, loading an old NMF namespace before installing its newer source version can cause a same-process CellChat requireNamespace check to fail even though the on-disk package installed correctly. Preserve installation/check logs and fresh-session results separately.

Certification requires the real-data R→HGNN→R technical loop and its nonempty actual PRS output. CLI/import success, successful environment solve, or namespace loading alone is not the official-demo completion criterion. Actual versions used by the successful run supersede this bootstrap recipe in the release lock; remove machine-specific prefixes and private library paths from any public environment export.
