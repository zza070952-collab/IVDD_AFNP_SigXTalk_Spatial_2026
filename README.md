# IVDD fixed-program and official SigXTalk computation

This source-code repository contains the study's own computational pipeline for adult human fixed-program projection, genuine raw AF/NP model-input preparation, an official SigXTalk run, frozen adult mouse spatial context and evidence integration. Optional V4 and compact-supplement authoring tools are documented in [Authoring reproduction](docs/AUTHORING_REPRODUCTION.md). The publication contains code, documentation and the small fixed Top25 membership/lock/provenance resources. It contains no experimental raw measurements or instrument files, supplied oligo sequences, manuscript content or payloads, generated figures/tables/workbooks, raw matrices, individual-cell barcode tables, complete pathway outputs, trained weights, review archives or vendored third-party implementations. Fitted cNMF spectra, loadings and other model weights remain private.

The repository is [IVDD_AFNP_SigXTalk_Spatial_2026](https://github.com/zza070952-collab/IVDD_AFNP_SigXTalk_Spatial_2026). No licence has been selected for this own-code release; all rights are retained pending the study owner's choice. Third-party projects retain their own licences. Citation author names and an archived release identifier remain pending. Repository availability, computational completion, experimental provenance and a clean-machine reproduction are separate claims.

Start with [environment setup](docs/ENVIRONMENT_SETUP.md), then copy the public configuration examples into private files and set real cache/environment locations. Public examples use only portable paths. The human module's [provenance](docs/FROZEN_K5_PROVENANCE.md), [human guide](README_HUMAN.md), [raw-selection guide](README_RAW_SELECTION.md), [official SigXTalk input guide](docs/SIGXTALK_INPUT_AND_EXECUTION.md) and [spatial guide](docs/SPATIAL_PUBLIC_REPRODUCTION.md) explain the component contracts.

The [authoring guide](docs/AUTHORING_REPRODUCTION.md) navigates the V4 human, communication/spatial, optional experiment, workbook and spatial-cache tools; compact human, communication/spatial and workbook tools; and common PDF/DOCX formatting, reference-replacement and visual-QA utilities. These tools require the documented external inputs and read-only private caches. A source-only clone is not a complete authoring dataset. Generated artifacts stay in ignored or external private output directories.

The optional [25 October main-figure revision](docs/MAIN_FIGURE_REVISION_20261025.md) adds the original overview Figure 1, replots old Figure 1B–E as Figure 2A–D and old Figure 5B–G as Figure 6A–F, preserves old Figures 2–4 byte-for-byte as Figures 3–5, and provides semantic reference/DOCX editing and QA code. Earlier pipeline numbering remains historical. This module requires external frozen inputs and private manuscript/plan/legend files; no research measurements, manuscript text, full legends or generated artwork accompany the code.

The stages are `all`, `human`, `raw-selection`, `sigxtalk`, `spatial`, `integrate`, `figures` and `audit`. The complete run retrieves public inputs, prepares the donor-resolved raw model input, generates adult human donor summaries, completes or verifies the single spatial depth check **before** the main formal model, completes the real technical R→Python→R closure and formal official SigXTalk run, integrates measured evidence, exports figures and audits actual outputs. Missing inputs, incomplete official closure and changed frozen inputs fail explicitly; a list of empty directories is never accepted as completion.

Raw mode supplies the full own-code route from the released matrices. It reuses the original locked K5 rather than silently refitting cNMF. An explicit historical fitting command is documented separately. Tu's released expression matrices contain published normalized values and are not called raw UMI counts. The SigXTalk input uses genuine GSE230808 integer count matrices and a fixed, independently recomputed donor/state selection.

Cached mode reuses actual cell-level QC/identity/scores and raw matrix files, with hashes and explicit skip receipts. It does not relabel historical SigXTalk predictions as a new run. Existing current model inputs are independently reselected and verified read-only, preserving their byte hashes once the new model has trained. Existing completed official models are verified against their frozen configuration, trained inputs, prediction hashes and pinned source. A completed HGNN can resume downstream PRS; it is not silently retrained.

The spatial sensitivity has one frozen100-UMI target, one seed, fixed ROI geometry and one draw. A valid completed check with matching configuration, ROI and protected-input hashes is reused without drawing again. Changed or partial depth outputs stop execution for review. No threshold search is performed. The [output contract](docs/EXPECTED_OUTPUTS.md) and [execution boundaries](docs/PIPELINE_BOUNDARIES.md) list what a completion claim does and does not establish.

The assembled workflow has technical tests and component checks. The existing CI runs `python -m unittest discover -s tests -v` and `python scripts/11_quality_audit.py --source-only`; the number of tests may grow. The separate publication gate `scripts/authoring/audit_public_release.py` inspects actual Git index blobs, and `scripts/authoring/common/smoke_synthetic.py` exercises generic document fixtures locally with its optional dependencies. These are small structural/source checks, with no GEO downloads, model training or substitution of fixtures for research data. Local cache smoke checks on 25 October 2026 exercised the available authoring inputs; syntax-only and synthetic-only checks are identified separately in the [authoring guide](docs/AUTHORING_REPRODUCTION.md). None establishes an independent clean-machine raw-to-all-final reconstruction. Figure export records source hashes, and visual inspection remains a separate requirement.

Human donor expression is descriptive, Tu clinical-grade mapping remains unresolved, and AUCell/UCell scales are separate. Receptor-component joins do not fit ligand-specific downstream causality. SSC labels do not establish TF activity. Mouse genotype is confounded with capture, fixed cores are provisional and depth sensitivity weakens spatial specificity. The canonical `run_all.sh`/`scripts/run_project.py` pipeline has no wet-lab stage and does not generate experimental Figure 5. Separately invoked [V4 experiment-authoring code](scripts/authoring/v4/experiments/README.md) can analyze authorized private workbook/protocol inputs and generate conditional internal experiment figures, including Figure 5; those outputs retain `INTERNAL_REVIEW_SOURCE_UNRESOLVED` and do not establish laboratory authenticity or formal release approval. No combined LR×PA×PRS biological score is generated.
